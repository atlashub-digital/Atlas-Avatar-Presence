# AAP-LICENSE-001 · Rights, licenses and asset attribution checklist

**Do not assume that MIT/open-source application source licenses apply to bundled avatar models, voice recordings, VRMA animations, image assets, SDKs or training sets.** Every external component must be independently reviewed by engineering/legal before commercial distribution.

| Reference | Verify |
| --- | --- |
| [ARPA AVATAR](https://github.com/ARPAHLS/avatar) | code license, Electron app dependencies, bundled characters, VRM/VRMA motions, binary release rights |
| [three-vrm](https://github.com/pixiv/three-vrm) | source license and version compatibility |
| [VRoid Studio](https://vroid.com/en/studio) | model export and character asset commercial terms |
| [Live2D Cubism](https://www.live2d.com/en/) | SDK/editor distribution and per-company terms |
| [Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber) | source code license and explicit commercial-use constraints |
| [Hermes](https://github.com/NousResearch/hermes-agent) | source license and upstream provider APIs/services |
| [OpenClaw](https://github.com/openclaw/openclaw) | open-source license, plugins, device capability policy |

## Required per-character media manifest
Author/rights owner, version, approved filenames, original URL/file ID (**private references kept outside public Git**), checksum, redistribution permissions, audience/territory, likeness consent, synthetic voice disclosure where applicable, allowed derivative adaptations, retention/revocation.

## Public repo
Do not place Helena's official PNGs or prospective 3D files in GitHub until rights/visibility reviewed. Synthetic sample references do not transfer rights.
